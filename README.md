# Creative Claude

Instalador de la suite de herramientas de creación de Proher Natura para Windows: **Lienzo** (imagen), **Trazo** (vectores), **Corte** (video), **Revelado** (fotos), **Prensa** (PDF), **Movimiento** (motion graphics) y **Página** (maquetación).

## Cómo instalarlo

1. Entra a [Releases](../../releases/latest) y baja `Creative-Claude-Setup.exe`.
2. Ábrelo. Se instala solo, sin permisos de administrador.
3. En Creative Claude pulsa **Instalar todo**. Las herramientas se bajan de esta misma página y se verifican antes de instalarse.

Si Windows muestra «Windows protegió su PC», pulsa **Más información** y luego **Ejecutar de todas formas**: el instalador aún no está firmado.

## Créditos y licencias

Las herramientas son versiones modificadas de las aplicaciones de código abierto del equipo ArtCraft (PhotoCraft, VectorCraft, FilmCraft, LightCraft, PdfCraft, EffectCraft y DesignCraft), con licencia MIT o Apache-2.0.
